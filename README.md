# dataro-images

Public images for Dataro's transactional emails, served with GitHub Pages.

Emails that have already been sent link to these files, so **don't rename, move or delete anything in `email/`**. To change a logo, add a new file with a new name and point the templates at it.

| File | Use |
|---|---|
| `email/dataro-logo-black@3x.png` | Light backgrounds |
| `email/dataro-logo-white@3x.png` | Dark backgrounds, where the email controls dark mode |
| `email/dataro-logo-dark-mode-safe@3x.png` | Default. Black mark with a white halo, so it stays readable when Gmail or Outlook force-invert colours |

All logos are 648×162 (3× of 216×54).
